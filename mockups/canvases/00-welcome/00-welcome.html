super-prototyping

github.com/ReScienceLab/super-prototyping

Clone and design product UI as self-contained HTML artboards on a local tldraw canvas. Drop an .html file into a folder and it shows up here as a shape.

Three skills, one workflow

/clone-prototype Copy a real app's screens. Grid the capture, sample it by eye, name the type face, then generate.
/new-ui-mock Design new screens with no reference, on tokens that already exist, empty and error states included.
/prototype-canvas Run and operate this canvas: folders, layout.json rows, the force refresh.
