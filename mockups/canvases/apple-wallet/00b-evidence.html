Evidence 1/2

Token, then its light value and its dark override, then where the value came from. A token with no evidence is a guess.

--aw-font -apple-system,BlinkMacSystemFont,"SF Pro Text","SF Pro Display","Helvetica Neue",Helvetica,Arial,sans-serif

every type style in the file is Font(family: "SF Pro"); this is the platform stack that resolves to it on macOS and iOS

--aw-bg #FFFFFF / #000000

Figma variable bg/primary-base: the page, and (because it is the exact inverse of label/primary) the glyph inside an action button

--aw-black #000000

Figma variable system/black: the Dynamic Island, one value in both themes, which is why the island is invisible on the dark boards

--aw-white #FFFFFF

Figma variable system/white: the promo headline, its body copy and the GET pill. They stay white in dark because the card under them does not change

--aw-sep rgba(60,60,67,.3608) / rgba(84,84,88,.651)

Figma variable separator/non-opaque #3C3C435C / #545458A6: the 1pt inside border on every pass. Over the white Apple pass it renders #B9B9BB / #909092, which is what ref-01 and ref-d01 sample at 2x

--aw-blur rgba(255,255,255,.698) / rgba(40,40,42,.941)

Figma variable ui/background-blur #FFFFFFB2 / #28282AF0, behind Material Blur (BACKGROUND_BLUR radius 50). Over the page it renders #FFFFFF / #262627 in the footer band, which is what ref-01 and ref-d01 sample at 2x; in light it is therefore invisible

--aw-promo #C7BCA9

raw hex on the Get Started card, not a published variable and not redefined in dark: ref-02 and ref-d02 both sample #C7BCA9 at 2x

--aw-promo2 #B19F8E

raw hex on the card's bottom band, likewise one value in both themes

--aw-ink #000000 / #FFFFFF

Figma variable label/primary: the Wallet title, the clock, the action buttons, and the home indicator at 60%

--aw-blue #007BFE / #0385FF

Figma variable ui/accent: the GET label, the only accent on either screen

--aw-r-phone 52px

the repo's frame convention, not a value in the file: its screens are square-cornered 393 x 852 artboards

--aw-r-card 11px

Figma variable app-wallet/card-corner: every pass

--aw-r-promo 14px

Figma corner radius on the Get Started card, which also clips its illustration and its bottom band

--aw-r-pill 100px

Figma corner radius on the Dynamic Island, the home indicator, the two action buttons and the GET pill

--aw-t-b15 590 15px/20px var(--aw-font)

Figma type style SemiBold/15pt: the GET label

--aw-t-r17 400 17px/22px var(--aw-font)

Figma type style Regular/17pt: the promo body copy

--aw-t-b17 590 17px/22px var(--aw-font)

Figma type style SemiBold/17pt: the status-bar clock

--aw-t-b28 700 28px/34px var(--aw-font)

Figma type style Bold/28pt: the promo headline

--aw-t-b34 700 34px/41px var(--aw-font)

Figma type style Bold/34pt: the Wallet title

--aw-w 393px

Figma variable screen/width in the 393 mode

--aw-h 852px

Figma variable screen/height in the 393 mode
