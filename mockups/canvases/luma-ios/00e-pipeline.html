The toolkit these phases call

refkit griddraw a labelled grid so the capture is read with eyes, not sampled blind
refkit sampleflat fills, small-element modes and ink cores in one census
refkit hairlinerecover a 1pt rule’s true colour from a downscaled capture
refkit bandsink bands and the pitch between them → the real row height
refkit bbox / inkan element’s box; ink drops a neighbour sharing the window
refkit scancollapse a row or column to colour runs → the exact edge
refkit fontrank candidate faces at a common cap height, from a closed set
refkit shootrender a board, crop the phone, and prove it does not clip
refkit diffthe side-by-side and the numbers behind it, per region
refkit batchreplay every probe, reference against render, in one process
refkit tokensone shared :root; no var() that was never defined

Where the replica differs on purpose

Dynamic IslandMobbin composites it out of the capture; the frame spec draws it, so it is present in the replica and absent in the reference.
Corner masking--crop-phone masks the 52pt corners, so verification crops show rounded corners where the raw capture is square.
Hero, map, avatarsPhotographic content is a crop of the capture, not a redraw. Those regions measure near-zero by construction and prove nothing.

All eight land between 3.47 and 4.50 levels, mean 3.89, with the top 56 pt excluded. That residual is antialiasing and JPEG noise in the source, not layout: the p99 sits at 51–78 and is concentrated on glyph edges.
